# Changelog

All notable changes to this package are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-10-21

### Added

- Timeline dialogue strips with glyph pop, slash codes, and one voice clip per speaker.
- Color and size codes, panel fade in and out, and editor pitch preview while scrubbing.
- Unity 2021.3 and newer. TextMeshPro comes from the TextMeshPro package on 2021.3 and 2022.3, and from uGUI on 2023.2 and newer.
