# Basic panel

Use **GameObject → Timeline Dialogue → Create Panel**.

That creates a screen-space canvas, a dim panel, a TextMeshPro line, an `AudioSource`, and a `DialogueController`. If `DefaultSpeaker` is in the project, the menu assigns it.

Add a PlayableDirector, a Timeline, and a Dialogue Track bound to that controller.

The sample voices are part of the package (`Runtime/Voice`), not this folder. Importing the sample is optional.
